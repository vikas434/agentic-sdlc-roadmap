# Agentic SDLC Roadmap

A growing explainer on how to work on any repository, new or old, so that a coding agent can follow along and deliver predictably. It is built from my handwritten notes.

Site: https://agentic-sdlc-roadmap.vercel.app/

- `index.html`: the explainer page
- `raw/YYYY-MM-DD/`: the handwritten notes for each date, plus a typed copy
- `assets/gifs/`: the hand-drawn animations
